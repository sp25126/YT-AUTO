# Viral Podcast Cutter

## Execution Protocol:
1. Load `transcript.json` generated by `faster-whisper`.
2. Scan for hook candidates matching the 21 Hook Formulas (e.g., The Counter-Intuitive, The Extreme Stakes, The Direct Callout).
3. Run candidate hooks through `python .agents/skills/youtube-agent-skill/skills/yt-script/hookscore.py --hook "<opening_sentence>"`.
4. Only select segments where:
   - Hook score is > 75/100
   - Clip duration is strictly between 28 and 55 seconds
   - The end phrase resolves cleanly or forms a loop back to the start.
5. Output an Edit Decision List (EDL) with sound effect triggers (whoosh on scene switch, pop on keyword captions).
