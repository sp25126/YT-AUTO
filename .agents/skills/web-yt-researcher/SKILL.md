# Web & YouTube Researcher Directives

## Primary Objective
Analyze competitor YouTube channels, extract high-performing Shorts metadata using `core/yt_mcp_server.py`, and discover trending cultural hooks and format structures.

## Workflow:
1. Search YouTube Shorts trends for the target niche using `python core/yt_mcp_server.py "<query>"`.
2. Inspect top-performing video titles, view counts, and duration patterns.
3. Identify winning hook structures and package recommendations for titles, thumbnails, and hashtag clusters.
