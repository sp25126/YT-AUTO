# Visual Design Language (Vox / Editorial Documentary Style)
- **Canvas Resolution:** 1080x1920 (9:16 Vertical Full-Screen Takeover). Never use 50/50 split-screen.
- **Backgrounds:**
  - Light Editorial Mode: Warm tactile paper `#F4F1EA` with subtle `28px` dot-matrix grid `#D8D3C8` and radial vignette.
  - Dark High-Stakes Mode: Deep obsidian `#111318` with `#232730` `32px` grid lines and subtle film grain.
- **Pixabay Media Cutouts:** Frame fetched Pixabay videos/images inside tilted Polaroid/torn-paper cards (`borderRadius: 20px`, `boxShadow: 0 24px 48px rgba(0,0,0,0.35)`, `border: 4px solid #FFFFFF`) with a `-2deg` to `+3deg` rotation.
- **Accent Palette:** Vox Highlighter Yellow (`#FFE600`), Crimson Stamp Red (`#E63946`), Emerald Signal (`#10B981`), Ink Black (`#141413`).
