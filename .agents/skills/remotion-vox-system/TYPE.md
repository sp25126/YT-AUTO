# Editorial Typography Hierarchy
- **Primary Display / Numbers:** `Montserrat Black` or `Inter Black`, `96px–130px`, tight tracking (`-0.04em`).
- **Editorial Serif Accents:** `Playfair Display` or `Georgia Italic`, `64px`, used for setup words (*"The real problem is..."*, *"Outside in..."*).
- **Stamp / Pill Labels:** Uppercase monospace/bold `36px` inside a bordered stamp box (`border: 4px solid #E63946`, rotated `-4deg`).
